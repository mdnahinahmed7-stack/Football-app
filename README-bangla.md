# লাইভ ফুটবল স্কোর ও স্ট্রিমিং অ্যাপ — সেটআপ গাইড

## প্রজেক্ট স্ট্রাকচার

```
football-app/
├── backend/          → Node.js + Express API (স্কোর, ম্যাচ ও স্ট্রিম লিংক সার্ভ করে)
└── flutter_app/       → Flutter অ্যাপ (UI + ভিডিও প্লেয়ার)
```

## ১. ব্যাকএন্ড রান করা

```bash
cd backend
npm install
cp .env.example .env
npm start
```

- সার্ভার ডিফল্টভাবে `http://localhost:4000` এ চলবে।
- `/api/matches` → সব ম্যাচ (লাইভ/আপকামিং/ফিনিশড)
- `/api/matches?status=LIVE` → শুধু লাইভ ম্যাচ
- `/api/matches/:id` → একটি নির্দিষ্ট ম্যাচের বিস্তারিত (স্কোর + স্ট্রিম লিংক)
- `/api/matches/:id/streams` → শুধু স্ট্রিমিং লিংকগুলো
- Socket.IO দিয়ে প্রতি ৬০ সেকেন্ডে লাইভ স্কোর আপডেট পুশ করা হয় (`matches:update` ইভেন্ট)।

বর্তমানে `data/mockMatches.js` ফাইলে ডেমো ডেটা আছে। আসল লাইভ স্কোর পেতে
[api-football.com](https://www.api-football.com/) এর মতো কোনো ফুটবল ডেটা প্রোভাইডার থেকে
ফ্রি/পেইড API কী নিয়ে `.env` ফাইলে বসান, এবং `server.js`-এর cron জবের ভেতরে
mock ডেটার জায়গায় আসল API কল বসিয়ে দিন।

## ২. Flutter অ্যাপ রান করা

```bash
cd flutter_app
flutter pub get
flutter run
```

- `lib/services/api_service.dart` ফাইলে `baseUrl` ভেরিয়েবলটি পরিবর্তন করুন:
  - Android এমুলেটরে লোকাল ব্যাকএন্ড টেস্ট করতে `http://10.0.2.2:4000` ব্যবহার করুন (এটাই ডিফল্ট)।
  - রিয়েল ডিভাইস বা প্রোডাকশনে আপনার ডিপ্লয় করা ব্যাকএন্ডের URL বসান (যেমন Render/Railway/VPS এ হোস্ট করার পর)।

## ৩. অ্যাপের ফিচারসমূহ

- **হোম স্ক্রিন**: তিনটি ট্যাব — Live, Upcoming, Finished ম্যাচ
- **ম্যাচ কার্ড**: দুই দলের লোগো, নাম, স্কোর এবং লাইভ/সময় ব্যাজ
- **ম্যাচ ডিটেইল স্ক্রিন**: বড় স্কোরবোর্ড + উপলব্ধ স্ট্রিমিং লিংকের লিস্ট (কোয়ালিটি ও ভাষা অনুযায়ী)
- **স্ট্রিম প্লেয়ার স্ক্রিন**: `video_player` ও `chewie` প্যাকেজ দিয়ে HLS (.m3u8) বা সাধারণ ভিডিও স্ট্রিম চালানো
- **রিয়েল-টাইম আপডেট**: Socket.IO দিয়ে লাইভ ম্যাচের স্কোর/মিনিট স্বয়ংক্রিয়ভাবে আপডেট হয়

## ৪. গুরুত্বপূর্ণ পরামর্শ (Streaming Links সম্পর্কে)

স্ট্রিমিং লিংক ফিচারটি এমনভাবে বানানো হয়েছে যাতে আপনি **নিজের লাইসেন্সকৃত/বৈধ স্ট্রিম উৎস**
(যেমন নিজের CDN, অফিসিয়াল ব্রডকাস্টার পার্টনারশিপ, বা YouTube Live embed) ব্যবহার করতে পারেন।
কপিরাইটযুক্ত সম্প্রচার অবৈধভাবে রি-স্ট্রিম করা বেশিরভাগ দেশে আইনত দণ্ডনীয় — তাই প্রোডাকশনে
যাওয়ার আগে নিশ্চিত করুন আপনার স্ট্রিম সোর্সগুলোর সঠিক লাইসেন্স/অনুমতি আছে।
